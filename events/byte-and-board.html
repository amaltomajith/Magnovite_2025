Science & Humanities Technical Challenge

BYTE & BOARD 🧠🔗

"Circuit the Challenge, Byte the Victory"

Byte & Board is a four-round technical challenge blending logic circuits, binary and hexadecimal decoding, programming analysis, and cryptic password deduction. Teams will solve a series of interlinked puzzles across electronics, coding, and problem-solving disciplines to crack a final password—the fastest teams win.

Team Size: 6–8 Members Registration Fee: 500 INR Per Team ← Back to Events

Event Structure

Code 1: Logic Gate Circuit

Round 1

Participants solve logic gate circuit puzzle to get binary string (Key 1).

Code 2: Binary to Hex

Round 2

Teams decode binary string from Round 1 into hexadecimal string (Key 2).

Code 3: C Program Analysis

Round 3

Analyze complex C program with conditional/loop statements to get decimal string (Key 3).

Final Code: Password Creation

Round 4

Process all three keys using algorithm, Python code, and equation to form final password.

Rules & Regulations

Only registered teams may participate.
Each team receives a starting kit for Round 1 containing puzzles and essentials.
External electronic devices are prohibited except when specifically allowed (entering final password).
Teams proceed to the next round only after verification of their answers.
During the final round, only one team member may approach the laptop to enter the password.
Team size must be between 6-8 members.
Registration fee is 500 INR per team.
Teams must solve interlinked puzzles across electronics, coding, and problem-solving disciplines.
Final password must be entered on central laptop to win.
Fastest teams to complete all rounds and enter correct password win.
Teams must work together to solve logic circuits, binary/hex decoding, and programming analysis.
Any misconduct or rule violation will lead to immediate disqualification.
